# Reference-driven UI pass — October 7 (direction revised)

The user rejected category apps as aesthetic references. The following initial category study is superseded for visual decisions. The current references are Airbnb's 2025 release screens (spacing and grouping), Uber's redesigned app (direct task entry), Apple's Find My People screen (map context and recognizable people), and Things 3's typography and Dynamic Type examples (calm, readable lists).

Current direction: white canvas, sapphire controls, restrained blue surfaces, clear headings, recognizable recipient initials, concise call rows, and direct report entry. Remove oversized grey action tiles and overly boxed secondary content. Keep the actual campus map as the useful visual. No glass, copied brand assets, marketing imagery, or ornamental illustration. The earlier functional improvements can remain where they independently serve usability.

Reference screens reviewed: LiveSafe's Marymount home screen, Rave Guardian's Wichita State dashboard, SafeZone's CriticalArc wellbeing dashboard, SAFEHawk's Google Play previews, and Noonlight's official safety-button screen. Some references show older releases; these are layout references, not claims about every current deployment.

Apply LiveSafe's distinct action panels, Guardian's recognizable icon-led shortcuts, SafeZone's clear separation of help from routine tasks, SAFEHawk's campus-specific map and grouped resources, and Noonlight's one-action emphasis and generous touch areas.

Palette: sapphire #3157A5, navy #18243B, white #FFFFFF, pale blue #EEF4FF, muted slate #56627A, and red #B42335 reserved for urgent or error meaning. Manrope remains the single type family. Left-aligned labels, 20px page margins, 12px panel gaps, 16px corners, and 48px minimum controls.

Home: greeting → primary walk panel → Report / Help panels → campus map → collapsed updates. All core actions precede map content. Help: urgent calling area → campus directory with one tappable row per contact. Report shortcut opens the reporting flow directly, retaining saved drafts; the Reports tab remains the history view.

Review against brief: no rainbow tiles, decorative photographs, emergency-dispatch promise, or six-feature grid. SafelyGo retains its own blue-and-white identity, actual map context, and existing consent controls. Large icons communicate actions rather than add decoration.
