# Ten-minute presentation outline

Setup (up to 3 minutes): open two signed native builds or one device plus recipient device; check the live Railway backend; prepare campus owner and student accounts. Use fictional demonstration data and visibly label it.

| Time       | Demonstration                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 0:00–1:00  | Explain student problem, multi-campus scope and design                                                 |
| 1:00–2:00  | Show verified account and campus onboarding                                                            |
| 2:00–4:00  | Submit report; staff reviews and publishes a summary; another user sees map update                     |
| 4:00–5:00  | Open campus directory and show confirmed call without actually calling                                 |
| 5:00–7:00  | Invite/accept trusted contact, start sharing, show recipient position, stop and confirm access revoked |
| 7:00–8:30  | Explain API, PostgreSQL schema, tenant filtering, role guards and ApiClient pattern                    |
| 8:30–9:30  | Show test evidence, deployment process and a failure/permission-denial state                           |
| 9:30–10:00 | Explain original decisions, limitations and citations                                                  |

Interview preparation (up to 5 minutes): Explain why campus authority requires review; why public reports omit author/private content; how accepted contacts differ from staff; why server expiry is authoritative; why native background location needs device testing; how password hashes and session hashes differ; how transactions, SQL parameters, rate limits, migrations and the outbox improve reliability; how to restore the database.

Every contestant should understand and be able to explain the code they submit. Rehearse within the time limit and keep AI/copyright documentation ready.
