# October 6: product polish

The four equal oversized pictogram cards made Home feel like a prototype. Rework hierarchy around the product's primary story: a walk connected to trusted people. One wide navy feature with a detailed, restrained campus-sharing scene and an explicit button; Map and Report are compact secondary actions, Help is a clear horizontal call action. Keep information left-aligned. Drawings must describe the task, never pretend to be measured map data.

Retain navy #18243B, sapphire #3157A5, white #FFFFFF, ice #F6F7FB, lavender #EDF0FA, slate #56627A. System sans serif, 28/34 screen titles, 22/28 feature title, 16/22 actions, 14/21 secondary copy. Use 20-pixel screen gutters, 16-pixel content rhythm, 20-pixel feature corners, 16-pixel forms, 12-pixel buttons. No shadows, decorative gradients, orange, mascots or editorial typography.

Layout: compact brand/account header → greeting → walk feature → Map/Report actions → Help → optional campus updates. Standard full-width bottom navigation with a subtle selected icon capsule; no floating bordered navigation box. Setup shows connected stage markers, without repeating the current stage above the same labels. Category illustrations sit beside concise labels, reducing visual bulk.

Critique before implementation: campus sharing is the distinctive element. Uniform cards, independent giant icons and heavyweight borders do not tell its story. Keep richer detail inside the walk illustration, let spacing and type carry the rest. Preserve all access, error, stale-location and emergency information.

## Further refinement

The navy feature plus uniformly framed white cards still reads as assembled components. Move to a white canvas, Manrope typography with explicit regular/semibold/bold faces, grouped settings rows and unframed secondary actions. Home's primary story gets a photographic blue-hour campus walk image; interface text remains real accessible text below the image. Keep instructional SVG sharing diagrams inside setup, where they explain access rather than decorate Home. Use a single calm blue accent, no orange, artificial shadows or editorial treatment. Home composition: compact header → greeting → photo-led walk feature → two compact actions → Help → optional updates. Review: imagery supplies human campus context, icons explain functions, labels remain literal; no claims of safe routes, dispatch or actual campus photos.

## Current direction: no campus photos

Remove generated campus photos from Home and sign-in following explicit rejection of both photo styles. Home uses the instructional phone-to-people SVG with short captions, rather than a fictional campus scene. Sign-in stays focused on identity and fields. Retain Manrope, white canvas, blue/navy palette, calm tinted controls and functional map/report pictograms. Visual storytelling comes from access, progression and measured state. Earlier photo proposals above are superseded.

Replace decorative illustration-led hierarchy with live campus context: a compact walk action, an actual campus map preview, and clear Report/Help actions.
